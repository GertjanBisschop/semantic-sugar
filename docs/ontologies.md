# Ontology Models

`semantic-sugar` ships with pre-defined models for:

- [Data Catalog Vocabulary (DCAT)](https://www.w3.org/ns/dcat)

# Usage

Import them from `semantic_sugar.ontologies.dcat`:

```python
from semantic_sugar.ontologies.dcat import (
    Catalog,
    Dataset,
    Distribution,
    DataService,
)
```
